# Answer instructions

Read the question carefully and address each explicit part using only relevant, user-provided facts. Do not invent experiences, results, metrics, qualifications, motivations or causal details. If essential information is missing, say so briefly rather than guessing.

Write in the first person with clear, natural spoken English. For a one-minute answer, aim for roughly 75–100 words; cover the question without filler or unrelated detail. Use a logical progression and brief transitions. Return the answer alone as spoken text, without labels, source notes or instructions.

Return three to five short, meaningful, non-duplicate keywords or phrases copied exactly from the answer. Choose phrases that are spread through the answer. Do not include markup, headings or summaries.
